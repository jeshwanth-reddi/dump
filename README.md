# Kunal Jain - Personal Website

A beautiful, modern personal website built with React, TypeScript, and Tailwind CSS. Deployed on Cloudflare Pages with custom domain `kunal-jain.com`.

## 🚀 Features

- **Modern Design**: Beautiful gradient backgrounds with glassmorphism effects
- **Responsive**: Fully responsive design that works on all devices
- **Fast**: Built with React and optimized for performance
- **Accessible**: Semantic HTML and proper accessibility features
- **SEO Friendly**: Optimized for search engines

## 🛠️ Tech Stack

- **Frontend**: React 18 with TypeScript
- **Styling**: Tailwind CSS
- **Fonts**: Inter from Google Fonts
- **Hosting**: Cloudflare Pages
- **Domain**: kunal-jain.com (managed through Cloudflare)

## 🏃‍♂️ Getting Started

### Prerequisites

- Node.js 16+ 
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/kunalpjain/aboutme.git
cd aboutme
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## 📦 Build for Production

```bash
npm run build
```

This builds the app for production to the `build` folder.

## 🚀 Deployment

This website is automatically deployed to Cloudflare Pages when changes are pushed to the main branch.

### Cloudflare Pages Configuration

- **Build command**: `npm run build`
- **Build output directory**: `build`
- **Root directory**: `/`
- **Node.js version**: 18

### Custom Domain Setup

1. Domain purchased and managed through Cloudflare
2. DNS records automatically configured
3. SSL/TLS encryption enabled
4. Custom domain: `kunal-jain.com`

## 📝 Customization

To customize this website for your own use:

1. Update personal information in `src/App.tsx`
2. Replace email and social links
3. Add your own projects and experience
4. Customize colors in `tailwind.config.js`
5. Update the domain name in deployment settings
